diff = max of: mean |dB| change over a 16-band x 23 ms spectrogram, worst single 23 ms frame / 3, and the same on the
stereo side channel (so Width counts). Level changes count too. >= 1.0 dB = audible.
'as rolled' = on the sound exactly as GENERATE made it; 'module on' = with that knob's section switched on
(e.g. Osc B knobs with Osc B on, LFO knobs with some LFO amount, Clap Gap with Claps > 0).
Skipped (need live MIDI, not a single note): glide, bend, velocity, voice mode, one shot (note-length behaviour);
master/limiter are output level.
